# Explicit source-bound boundary attack rehearsal

This is an opt-in compiler seam, not a default renderer relaxation. The ordinary
compiler still rejects `authored_dynamics.performance_required`.

`perform_document_practice_with_boundary_attacks` retains the exact Document and
creates a private interpretation projection removing only the typed authored
boundary lane. Every source statement and every performed occurrence must belong
to a proven terminal/opening pair. Other lifted controls need separate semantics.
The schedule uses the actual qualified practice traversal, not an independently
assumed traversal. A repeated jump cannot invent an adjacent pair.

The app entry point `plan_source_with_boundary_practice_joint_policies_and_pizzicato`
constructs attack witnesses from actual consolidated PlaybackNotes joined to
performed events and measure occurrences. It changes only selected fresh attacks
inside the proven opening visit. Existing note-on controls retain precedence;
already sounding or incoming-tied voices are not retargeted. Changing envelopes
are not flattened. Constant note-on realization is exact percentage × 9/10,
rounded integer velocity plus the residual constant gain. Receipts retain the
exact rational, both envelopes, pair indices, original source digest and separate
projection digest. Note starts, lengths, releases, routes and envelope knot times
are unchanged.

This narrow rule does not invent persistent dynamics after the opening visit.
Coverage checks require no new attacks between that visit's end and the next
legacy numeric assignment/end. A route discontinuity before that assignment is
not interpreted as carry. Otherwise a specific coverage error is returned, not a
silently incomplete plan. Zero or out-of-range velocity requires separate sound
semantics. The source model retains all authored values regardless of realization.
