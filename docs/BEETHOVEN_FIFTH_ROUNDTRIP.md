## Reproduce

Use a checkout of the verified commit and a directory containing the eight pinned source files. The harness verifies the XML SHA-256 and the matching MusicXML payload inside each MXL before conversion.

```sh
cargo build --locked -p scorestream-cli
python3 scripts/check_beethoven_import.py target/debug/scorestream /path/to/pinned-inputs \
  --movement-i-contract crates/scorestream-cli/tests/fixtures/fifth-i-irregular-measures.json \
  --movement-ii-contract crates/scorestream-cli/tests/fixtures/fifth-ii-irregular-measures.json \
  --movement-iii-contract crates/scorestream-cli/tests/fixtures/fifth-iii-irregular-measures.json \
  --movement-iv-continue-final-ending --compare-note-events
```

The exact contracts preserve the written meters and existing measure lengths: I's cadenza, II's short final measure, and III's four short measures. For IV, the explicit final-ending route admits the unclosed ending without adding an endpoint. These are fixture-scoped choices, not global padding or truncation rules.

The independent comparison covers authored note events, rests, exact times, chord membership, pitch/transposition, grace attachment and sound ties. It is **not** proof of complete engraving, dynamics/tempo realization, MIDI mixing, end-to-end playback or a finished WAV. See [the transcript scope](SOURCE_NOTE_EVENT_TRANSCRIPT.md) for details.
