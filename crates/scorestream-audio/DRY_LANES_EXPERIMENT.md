# Isolated dry-lane envelope experiment

This is not a renderer, sound-route authorization, or full-performance claim.
Existing native/default and rehearsal rendering paths are unchanged.

`DryEnvelopeSchedule::prepare` accepts the opaque source-qualified technique
plan, retains its source hash, fingerprints the whole immutable playback plan,
and retains original per-note EnvelopePoints. `verify_plan` checks both bindings.
The serialized receipt is not deserializable into authorization. Indexes follow
plan note order. `apply` multiplies an exclusively owned dry stereo block in f64,
without mixing, changing musical time, clamping gain, or discarding residuals.
Duplicate offsets are right-continuous steps; positive-time segments are linear
at each sample. Empty envelopes mean unity; an omitted initial point starts at
unity. The explicit `HoldLastGainAtNoteOffV1` policy evaluates the original curve
at the written audible note duration and preserves that gain through the synth
release tail. It does not invent a new tail duration.

Frames use the existing nearest-sample conversion. This does not remove the
native ordinary note API's 64-frame scheduling quantization. A future adapter
must reconcile and disclose that policy explicitly; it must not silently shift
onsets to wait for capacity. No current renderer calls this module.

The crate-private `DryLane` state machine is an integration seam. Its backend
provider must synchronously report *all playing voices*, including released
voices, for a non-aliased lane at the completed PCM cursor. Admission requires
that cursor equal the scheduled onset, previous owner receive NoteOff, and no
playing voices remain. No expiry timeout or arbitrary score/lane quota exists.
The provider trait is trusted internal backend code, not an external boolean
certificate. Native synthesis and ownership operations must be single-threaded
or equivalently synchronized. No caller may steal voices to make room.

When lanes are exhausted at an actual onset, request additional independent
capacity (possibly another synth) or return explicit admission failure. Never
wait and move a musical attack. Cross-instance PCM bit equivalence has NOT been
established: scratch proof observed a maximum difference of 3.3576e-6 between
fresh and reused synth histories. Same-history isolated lane references match.

Focused tests cover steps, ramps, explicit tail gain, transactional failure,
no timeout release, owner mismatch and refusal to delay an onset. An opt-in
`real_two_lane_pcm_reference` test accepts a local PCM fixture generated by the
separate installed FluidSynth 2.4.4 / hashed TimGM two-lane experiment. It compares
both isolated lanes and applies the Rust curve in 137-frame partitions against
an independent Python reference (tolerance 1e-17). No samples or soundbank are
bundled with this change. This synthetic test is not a real-score authorization.
